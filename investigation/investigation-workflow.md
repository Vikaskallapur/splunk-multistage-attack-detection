# SOC Investigation Workflow

1. Alert is generated by Splunk.
2. Analyst reviews the alert severity and risk score.
3. Identify the affected account.
4. Identify the affected host.
5. Review timestamp and authentication activity.
6. Examine source network address when available.
7. Review Logon Type and authentication process.
8. Correlate failed and successful login events.
9. Review Windows process creation events (Event ID 4688).
10. Determine whether the activity is benign or suspicious.
11. Document findings and recommended response.

## Important Windows Event IDs

- 4624 — Successful Logon
- 4625 — Failed Logon
- 4688 — Process Creation
